# Holdout results

`before.json` and `after.json` record the English holdout; `../ja/holdout-report.json` records Japanese. Run `node --test tools/calibrate/holdout.test.ts tools/calibrate/ja-cleanup.test.ts` to check the measured sizes and Japanese cleanup. Each report compares 318 scripts. English has 317 exact heights, mean absolute width error 0.039 and maximum 4.375 workspace units. Japanese has 317 exact heights, mean 0.203 and maximum 4.395.

The raw-json/L6 player has a real procedure root `Yt{7~R5HQLmO$dUww)Gx` which the editor did not return on the successful retries. An earlier editor load reported that root and a VM-generated compact variable reporter as zero-sized, together with six non-root entries, after a comment positioning error. Neither is a usable size measurement. The report checks source roots in both directions and explicitly requires this one missing procedure as a known editor quirk; unexpected missing roots or invalid measurements fail the test. The compact reporter ID was generated by the VM and did not appear on the retry, and it is not a source top-level block. The missing procedure is excluded from the statistics, not counted as a pass.

Japanese measurements use `https://turbowarp.org/editor?locale=ja`. They include the original fixtures, 24 holdouts, and `allblocks.sb3`, with original and Clean up Plus positions. `tools/calibrate/measure-ja.mjs` reuses an open agent-browser session named `calibration-ja`; open the Japanese editor first. Japanese structures and dropdown values were captured by `ja-structure.mjs` and `ja-options.mjs` from allblocks, and `ja-glyphs.mjs` measured Japanese characters in SVG. These browser measurements depend on the editor build and installed fonts.

The editor source includes `ja-Hira` in its locale list. Loading the live editor with either `?locale=ja-Hira` or `?locale=ja-hira` returned the regular Japanese block label `%1 歩動かす` in this session. Hiragana-specific metrics were not calibrated.

`allblocks.sb3` is generated by `tools/calibrate/make-allblocks.py`. It exercises non-hidden, non-shadow catalog entries plus a procedure and a mixed nested stack; it is not complete combinatorial coverage. `screens/after-ja.png` shows the updated `scroll-after.sb3` in the Japanese editor, zoomed out to fit the target. The three newly placed comments clear their full scripts. The older blank comment at the top belongs to the source project and still covers part of its existing script.
